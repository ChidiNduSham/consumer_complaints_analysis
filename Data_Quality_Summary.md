Generated by the analysis notebook. Source: CFPB Consumer Complaint records, 1 May 2017 to 28 August 2023.

**Rows:** 62,516 | **Columns:** 12 (flat file, one row per complaint)

## Checks, findings and decisions

| Check | Finding | What it means | Action taken |
|---|---|---|---|
| Dictionary vs file | All 12 dictionary fields exist in the file and vice versa | Field definitions can be relied on | None needed |
| Primary key | Complaint ID is unique (0 repeats) | Complaint ID is a valid primary key; one row = one complaint | None needed |
| Duplicates | 0 fully duplicated rows; 1,494 rows share every field except the ID | Matching content with different IDs is most plausibly separate complaints, but a repeat consumer cannot be identified (no consumer ID) | Nothing removed; noted as a limitation |
| Missing: Timely response? | 1,494 blanks, every one on a complaint marked 'In progress' | Blank means 'no timeliness decision yet', NOT 'No' | Kept blank; excluded from the timely-response denominator and reported separately |
| Missing: Sub-issue | 10,858 blanks (17.4%); near-total for Money transfer and Mortgage, none for several other products | Mostly structural: some products simply have no sub-issues | Labelled 'Not recorded / not applicable'; not filled in |
| Missing: Company public response | 2,175 blanks (3.5%), including all 'In progress' complaints | The public response is optional; blank means none was posted | Labelled 'Not provided' |
| Missing: Sub-product | 7 blanks, all Checking or savings account | Too few to matter | Labelled 'Not recorded' |
| Dates | All dates parse; range 2017-05-01 to 2023-08-28; 0 negative intervals | Date logic is consistent (received is never before submitted) | Converted to datetime; 2017, 2023 and Aug-2023 flagged as partial periods |
| Forwarding interval | Median 0 day(s), maximum 275; 435 intervals over 30 days | Highly skewed; a few very long intervals | Kept and flagged (not deleted); reported with medians and shares |
| Categories: spelling and case | No spelling, case or spacing variants found in any categorical column | Category labels are already consistent | No re-spelling needed |
| Unusual: 'Web Referral' | 90 records labelled 'Web Referral' beside 10,766 'Referral' | Probably the same channel under two labels, but the dictionary does not say | Original kept; a grouped `channel_group` merges them for channel comparisons (assumption) |
| Unusual: response 'Closed' | 8 records have the bare label 'Closed' (no explanation or relief detail) | Cannot be assigned to any other closed category without guessing | Kept in descriptive counts; excluded from H2 and reported |
| Product detail | Product has 9 categories; the 3 smallest are Student loan (39), Payday/title/personal loan (333) and Vehicle loan or lease (633) | Small groups have unstable percentages and violate chi-square expected-count rules | Described individually; combined into one group for hypothesis tests |
| Preparation | All 62,516 rows retained; 13 derived fields added (year, month, quarter, interval, bands, flags, groups) | No information lost; original columns unchanged | Cleaned copy saved separately; original file preserved |

**Principle applied:** no row was deleted and no missing value was invented. Blanks received explicit labels, and unusual values were flagged and tested rather than removed. The original data file is unchanged (hash verified in the notebook).
